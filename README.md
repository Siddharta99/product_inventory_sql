# Product Inventory (SQL Edition)

A command-line product management system built with Python and SQLite.

## Features
- Add, view, find, update, and delete products
- Persistent storage with SQLite
- Honest feedback: every operation reports success or failure truthfully
- Crash-proof: invalid input and missing data are handled gracefully

## Tech
- Python 3
- SQLite (sqlite3 module)

## How to Run
1. Download this repository
2. Run: python sql_app.py
